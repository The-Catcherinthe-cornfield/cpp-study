# C++ 练习

记录我的 C++ 学习过程和练习代码。

## 学习进度

- **第一阶段**：变量、常量、运算符、`if` / `switch` 流程控制
- **第二阶段**：`for`、`while` / `do-while` 循环
- **第三阶段**：一维数组 —— 最值、逆置、冒泡排序
- **第四阶段**：二维数组 —— 遍历、统计、矩阵转置
- **第五阶段**：函数 —— 定义与返回值、值传递、声明与定义分离、多文件编程
- **第六阶段**：指针 —— 取地址与解引用、`const` 与指针的三种组合、空指针与野指针、指针作函数参数、指针遍历数组、用指针写排序
- **第七阶段**：递归 —— 用打印观察调用栈（阶乘）
- **第八阶段**：结构体 —— 定义、结构体数组、结构体指针（`->`）、用指针遍历结构体数组、嵌套结构体、结构体作函数参数、按名字查找
- **第九阶段**：内存 —— 内存四区（全局 / 静态 / 栈 / 堆）、野指针与悬空指针、`new` / `delete`、`new[]` / `delete[]`
- **第十阶段**：函数高级 —— 默认参数、函数重载、重载决议与二义性
- **第十一阶段**：引用 —— 引用绑定、引用传参、`const` 引用、返回引用的陷阱
- **第十二阶段**：类与对象 —— 构造函数 / 析构函数、`class` 与 `struct` 的默认访问权限、封装（private + getter/setter）、拷贝构造、编译器隐式声明构造函数的规则、深拷贝与动态数组资源释放、构造函数初始化列表、成员对象的构造 / 析构顺序、静态成员变量与静态成员函数、对象大小与成员存储、`this` 指针与链式调用、`const` 成员函数与常对象、`mutable` 成员
- **第十三阶段**：友元 —— 全局函数作友元、友元类、指定成员函数作友元、前置声明与定义顺序
- **第十四阶段**：运算符重载 —— 坐标相加、流输出、前置与后置递增、拷贝赋值、相等比较与函数对象
- **第十五阶段**：继承 —— 基类成员的访问权限、公有 / 保护 / 私有继承、派生对象中的基类子对象

## 怎么切换正在练习的文件

一个程序里只能有一个 `main()`，所以工程中除了当前要运行的那个文件，其余都设了**「从生成中排除」**（图标上会显示红圈）。

切换方法：在解决方案资源管理器里右键文件 → **属性** → 把「配置」和「平台」都选成**所有** → **配置属性 → 常规 → 从生成中排除** → 选「是」或「否」。

注意 `函数练习三a.cpp` 和 `函数练习三b.cpp` 是一对，必须同时参与编译（一个提供 `main()`，一个提供函数定义）。

## 新增对象练习说明

- 工程目前启用 `继承练习三.cpp`（派生对象大小）。继承练习一、二和之前的运算符重载练习在四种配置下设为「从生成中排除」。
- `运算符重载练习四.cpp` 演示已有对象之间的拷贝赋值。若要用一个 `HeapScore` 初始化另一个，还需自定义拷贝构造函数来独立分配内存，避免默认复制指针导致重复释放。
- 在线人数统计文件已由 `对象特征八.cpp` 重命名为 `对象特征练习八.cpp`，练习内容不变。
- `对象特征练习九观察对象大小.cpp` 的 `sizeof` 结果与编译器、平台及内存对齐有关；静态数据成员由类共享，普通成员函数不为每个对象额外保存一份函数代码。
- `对象特征练习三拷贝构造.cpp` 中按值返回对象时，编译器可能省略拷贝，因此不同编译配置下打印次数可能不同。
- `对象特征练习四系统何时自动构造.cpp` 使用 C++20；当前的 `Person p1("李四", 20)` 是圆括号形式的聚合初始化，不是编译器自动生成了有参构造函数。用户声明构造函数会影响默认构造函数的隐式声明；单独声明析构函数不会阻止默认构造和拷贝构造。
- 深拷贝练习当前演示 `Playlist b = a` 的拷贝构造；尚未实现拷贝赋值运算符，请勿把已有对象之间的 `b = a` 当作深拷贝使用。构造参数请使用正数：当前 `n <= 0` 分支只调整分配长度，没有同步调整成员 `count`。

## 关于文件编码

工程已经在编译选项里加了 `/source-charset:utf-8`，所以新建的 `.cpp` 文件只要用 UTF-8 保存（VS、VS Code 默认都是），**有没有 BOM 都能正常编译**，不用再手动处理。
