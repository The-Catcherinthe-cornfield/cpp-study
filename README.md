# C++ 练习

记录我的 C++ 学习过程和练习代码。

## 学习进度

- **第一阶段**：变量、常量、运算符、`if` / `switch` 流程控制
- **第二阶段**：`for`、`while` / `do-while` 循环
- **第三阶段**：一维数组 —— 最值、逆置、冒泡排序
- **第四阶段**：二维数组 —— 遍历、统计、矩阵转置
- **第五阶段**：函数 —— 定义与返回值、值传递、声明与定义分离、多文件编程

## 怎么切换正在练习的文件

一个程序里只能有一个 `main()`，所以工程中除了当前要运行的那个文件，其余都设了**「从生成中排除」**（图标上会显示红圈）。

切换方法：在解决方案资源管理器里右键文件 → **属性** → 把「配置」和「平台」都选成**所有** → **配置属性 → 常规 → 从生成中排除** → 选「是」或「否」。

注意 `函数练习三a.cpp` 和 `函数练习三b.cpp` 是一对，必须同时参与编译（一个提供 `main()`，一个提供函数定义）。
